# 08 | Operación

**Objetivo:** aprender del uso real, atender incidencias y comprobar si el valor se repite.

## Documentos sugeridos

- `metricas.md`: activación, tarea completada, repetición, soporte y resultados del cliente.
- `soporte_y_feedback.md`: canal, horarios, preguntas frecuentes y solicitudes.
- `incidentes.md`: impacto, acciones, comunicación y prevención.
- `costos_y_dependencias.md`: infraestructura, proveedores, API y mantenimiento.
- `privacidad_y_retencion.md`: qué datos realmente se conservan, cuánto tiempo y cómo se borran.

## Salida de fase

Se conoce si los usuarios terminan la tarea, vuelven a usar el producto, recomiendan/renuevan y cuánto cuesta atenderlos.
