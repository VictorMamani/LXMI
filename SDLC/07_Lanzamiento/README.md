# 07 | Lanzamiento

**Objetivo:** publicar de forma repetible, saber qué cambió y poder volver atrás.

## Documentos sugeridos

- `entornos_y_configuracion.md`: desarrollo, vista previa y producción; variables de entorno sin valores secretos.
- `procedimiento_de_lanzamiento.md`: pasos, migraciones, dominio, autorizaciones y responsables.
- `respaldo_y_retorno.md`: backup, prueba de restauración y camino de rollback.
- `notas_de_version.md`: cambios, limitaciones y destinatarios.
- `lista_previa_a_publicar.md`: permisos, privacidad, soporte, rendimiento y disponibilidad.

## Salida de fase

La versión piloto es accesible al grupo previsto, se puede identificar, y existe una ruta de recuperación razonable.
