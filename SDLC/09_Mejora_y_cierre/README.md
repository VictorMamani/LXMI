# 09 | Mejora y cierre

**Objetivo:** priorizar con evidencia y cerrar de forma responsable cuando deje de ser útil o viable.

## Documentos sugeridos

- `revision_de_resultados.md`: metas frente a datos, comentarios y fallos.
- `backlog_de_mejoras.md`: oportunidad, evidencia, prioridad, esfuerzo y responsable.
- `retrospectiva.md`: qué funcionó, qué no y qué aprender para el próximo proyecto.
- `plan_de_cierre.md`: fecha, clientes afectados, exportación/eliminación de datos, pagos pendientes y archivo del código.

## Salida de fase

Hay una decisión explícita de mejorar, mantener, pausar o cerrar. Si cierra, usuarios, datos y dependencias quedan tratados de forma clara.
