# Repository instructions

- Use English for all maintained documentation, UI copy, source comments, diagnostics, commit messages, and pull request descriptions.
- Preserve user-created profile names, mod names, filesystem paths, stable protocol identifiers, and existing data formats.
- Use fenced `mermaid` blocks for flows, states, sequences, entity relationships, and simple architectures in Markdown.
- Use fenced `plantuml` blocks for advanced UML or C4 models when Mermaid cannot express the model clearly.
- Do not draw diagrams or wireframes with ASCII art, box characters, manual arrows, or text-only traversal sequences. Use tables or lists for wireframe structure and visual tools when greater fidelity is needed.
- If a Mermaid or PlantUML rendering MCP is available, use it to validate or export diagrams. Otherwise retain the source and do not claim it was rendered or validated.
- Do not install or configure third-party MCP servers without an explicit user request.
- Treat browser demo validation separately from native Tauri IPC and actual game launch evidence.
